# tztoolbox — agent orientation

This repository is a multi-tool toolbox for Cursor, Claude Code, and OpenAI
Codex CLI. Author each artifact once under `shared/`; the `tzcli` binary
renders it into per-tool native trees and installs them.

## Layout

```
shared/                  canonical source of truth
  commands/              slash-command playbooks (.md)
  rules/                 always-on guidance (.md)
  skills/<name>/         Agent Skills standard layout
overrides/
  cursor/rules/          per-rule .mdc frontmatter
  cursor|claude|codex/   per-tool disabled.yaml
.cursor/ .claude/ .codex/   generated, committed for in-repo UX
cmd/tzcli/               Go entrypoint (Cobra)
internal/                pure-Go logic: render, installer, doctor, …
```

## Workflow

1. Edit under `shared/` or scaffold via `tzcli add <command|rule|skill> <name>`.
2. Regenerate native trees: `tzcli sync` (or `make sync`).
3. Validate: `make ci` (gofmt, golangci-lint, shellcheck on `install.sh`,
   `tzcli validate`, `go test`, build).
4. Commit on a feature branch and open a PR.

## Constraints

- Pure-Go for `internal/sync`, `internal/installer`, `internal/render`. Shell
  out only for `tzcli update` (git) and best-effort tool detection.
- All filesystem operations must be idempotent.
- SKILL.md frontmatter must keep `description` ≤200 characters and use
  third-person phrasing for cross-tool compatibility.
- Don't edit `.cursor/`, `.claude/`, or `.codex/` directly — they are
  regenerated by `tzcli sync`.

## Codex-specific notes

- Codex calls slash-command markdown files **prompts**; they live in
  `~/.codex/prompts/`, not `commands/`.
- Codex picks up this very file (`AGENTS.md`) as project orientation when the
  repo is opened.
